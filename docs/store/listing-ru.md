# Русская карточка магазина

## Основные данные

**Название:** Умный переводчик страниц

**Краткое описание:** Переводите целые веб-страницы и PDF через DeepSeek или OpenAI, с двуязычным режимом и постоянным локальным кэшем.

**Категория:** Продуктивность

**Поисковые фразы:** перевод страниц, двуязычное чтение, перевод PDF, DeepSeek, OpenAI

## Описание

Умный переводчик страниц переводит целые сайты, динамические интерфейсы, выделенный текст, редактируемые поля и текстовые PDF через выбранный вами AI-сервис.

Сначала это был личный инструмент для страниц, на которых обычные переводчики пропускали кнопки, описания товаров, подписи доступности или новый контент. Затем расширение было переработано для публичного использования и открыто для проверки: без рекламы, аналитики, телеметрии и собственной подписки.

Выберите DeepSeek или OpenAI, добавьте свой API-ключ и используйте любую совместимую текстовую модель, доступную вашему аккаунту. Сервис может брать плату за API-запросы; само расширение не продаёт перевод и не использует промежуточный сервер.

Возможности:

- Полный перевод страниц с поддержкой динамического контента и переходов внутри SPA.
- Оригинальный, переведённый и компактный двуязычный режимы чтения.
- Общие языковые правила и отдельные настройки перевода и вида для каждого сайта.
- Перевод описаний товаров с бережным сохранением брендов и имён собственных.
- Одна настраиваемая системная команда для выделенного текста и активного редактируемого поля.
- Необязательная компактная кнопка рядом с выделением, выключенная по умолчанию.
- Локальный разбор PDF, параллельный просмотр и скачивание переведённой копии.
- Ограниченный постоянный локальный кэш без повторной оплаты одинаковых запросов.
- Интерфейс расширения на русском и английском языках.

Конфиденциальность заложена в архитектуру. API-ключи и кэш хранятся локально в расширении. Текст страницы отправляется напрямую выбранному сервису только во время перевода. Поля, выделения и текст PDF отправляются только после явного действия. Переводы из приватных окон не записываются в постоянный кэш.

Исходный код, схема передачи данных, инструкция сборки и сведения о сторонних библиотеках открыты.

## Что нового в версии 0.2.2

Добавлена одна настраиваемая системная команда для перевода выделенного текста и редактируемых полей. Необязательная компактная кнопка рядом с выделением по умолчанию выключена. Настройки системного меню остаются согласованными при быстрых изменениях.
